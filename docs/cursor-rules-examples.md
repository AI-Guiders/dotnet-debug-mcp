# Cursor: примеры правил (копипаст)

Сохрани как `.cursor/rules/dotnet-debug-mcp-global.mdc` (или подключи к своему набору правил).

~~~mdc
---
description: Как отпускать приложение и завершать сессию при отладке .NET через dotnet-debug-mcp.
alwaysApply: true
---

# Dotnet-debug-mcp (глобально)

- **Отпускание приложения:** чтобы целевое приложение снова выполнялось после остановки на брейкпоинте — вызывай **debug_continue**. Для завершения сессии — **debug_stop** (он перед отключением шлёт continue, процесс не зависает). Не завершай процесс netcoredbg снаружи (taskkill): от этого MCP может уйти в Error; если приложение зависло — лучше вызвать debug_stop.
- **Пересборка цели:** перед пересборкой целевого exe/dll вызывай **debug_stop** — netcoredbg держит PDB открытым, иначе сборка падает с «файл занят netcoredbg.exe».
- **Attach:** для подключения к уже запущенному .NET-процессу используй **debug_attach** (workspace_path, process_id; опционально target_path для брейкпоинтов).
~~~
